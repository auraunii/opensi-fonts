# OpenSI Serif and OpenSI Mono

OpenSI Serif is designed for prose. OpenSI Mono is designed for code.

[Download the latest ZIP](https://github.com/auraunii/opensi-fonts/releases/latest/download/OpenSI-Serif-and-Mono.zip)

## Install

- **Windows:** Extract the ZIP and double-click `Install OpenSI.cmd` to install all five fonts for your Windows account.
- **macOS:** Extract the ZIP and use Font Book to select and install the five `.ttf` files.

OpenSI Serif includes Regular, Italic, and Semibold. OpenSI Mono includes Regular and Bold.

OpenSI Serif is distributed under the SIL Open Font License 1.1. See the included license and font change log. The package README explains the license status of OpenSI Mono.
